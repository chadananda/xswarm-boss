About Omarchy Defender

Learn Hyprland Shortcuts Through Gameplay

Omarchy Defender is a free, browser-based game designed to teach you the keyboard shortcuts used in Hyprland, the dynamic tiling Wayland compositor. Whether you're new to tiling window managers or looking to improve your speed, this game makes learning fun.

What You'll Master

  • Stage 1: Terminal Warfare - Window spawning, closing, navigation, and movement using vim-style keys (H/J/K/L)
  • Stage 2: Sector Command - Workspace management across 9 virtual desktops
  • Stage 3: Full Arsenal - 20+ application launch shortcuts for maximum productivity

Why Keyboard-Only?

Tiling window managers like Hyprland are designed for keyboard efficiency. By removing mouse dependency, you'll develop muscle memory that translates directly to real-world productivity. The game's "mouse contamination" system gently discourages reaching for the mouse, reinforcing keyboard-first habits.

Compatible With

While designed for Hyprland and Omarchy (the preconfigured Hyprland setup), the shortcuts taught in this game are similar to other tiling window managers including i3, Sway, and bspwm. The vim-style navigation (H/J/K/L) is universal across the keyboard-centric Linux ecosystem.
